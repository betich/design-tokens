# Token reference

Everything below is rendered from the live custom properties in
`src/styles/`, so it cannot drift from the build. Use the **theme** and
**brand** toolbar controls to watch the semantic layer move while the
primitives stay put.

## Semantic colour

The vocabulary components are allowed to name. Three families, and every one of
them flips with `[data-theme]`.

## Spacing

Padding, margin and gap share one scale. Each step is also emitted as a
utility, so `p-md`, `m-lg` and `gap-sm` are real classes.

<div className="gap-xs py-sm flex flex-col">
  <SpacingBar token="--spacing-p-2xs" />
  <SpacingBar token="--spacing-p-xs" />
  <SpacingBar token="--spacing-p-sm" />
  <SpacingBar token="--spacing-p-md" />
  <SpacingBar token="--spacing-p-lg" />

</div>

## Radius

<div className="gap-md py-sm flex flex-wrap items-end">
  {['none', 'sm', 'md', 'lg', 'xl', 'full'].map((step) => (
    <div key={step} className="gap-2xs flex flex-col items-center">
      <div
        className="bg-surface-accent size-14"
        style={{ borderRadius: `var(--radius-${step})` }}
      />
      <code className="text-content-muted text-[11px]">{step}</code>
    </div>
  ))}
</div>

## Elevation

Each shadow is recombined by the build from five separate parts.

<div className="gap-lg py-md flex flex-wrap items-end">
  {['sm', 'md', 'lg'].map((step) => (
    <div key={step} className="gap-xs flex flex-col items-center">
      <div
        className="bg-surface-raised border-line-subtle size-20 rounded-lg border"
        style={{ boxShadow: `var(--shadow-${step})` }}
      />
      <code className="text-content-muted text-[11px]">--shadow-{step}</code>
    </div>
  ))}
</div>
